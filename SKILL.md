# Meeting notes

Meetings live in `.fused/data/meetings/<id>/` as `meeting.json` beside the
recorded `audio.wav`. Transcription and summarisation run from the page
through `fused.ai` (local Whisper + local llama.cpp), not from these files.

## meetings.py
Lists, creates, reads, patches or deletes meeting records. Writes `.fused/data/meetings/<id>/meeting.json`.
- Args: `action` (str, default "list": one of list | create | get | update | delete), `meeting_id` (str, required for get/update/delete), `title` (str, default "", used by create), `patch` (str, JSON object, used by update; keys: title, notes, transcript, summary, speaker_names, duration_s, status, format, expected_speakers, calendar)
- Returns: list → `[{id, title, created_at, duration_s, status, has_summary, segments, speakers, excerpt, tasks, open_tasks, calendar_key}]` (`calendar_key` = `uid@start` of the linked calendar event, or null) (`excerpt` = first prose of the summary, ≤ 220 chars; `tasks`/`open_tasks` count the summary's checkboxes); create/get/update → the full meeting object; delete → `{"ok": true, "id": str}`
- Example: `{"action":"py","app":"meeting-notes","file":"meetings.py","args":{"action":"get","meeting_id":"20261028-171500-ab12cd"}}`

## recorder.py
Starts or stops a detached ffmpeg that writes `.fused/data/meetings/<id>/audio.pcm`. On Linux it captures the chosen output's monitor (+ chosen mic) over PipeWire/PulseAudio. On macOS the page records system audio with `fused.capture` into an ADTS `.aac` take file from `prepare`; ffmpeg follows that file as it grows and records the mic itself over AVFoundation, padded so it lines up with `started_at`. A bot cannot start a macOS recording without the page. A meeting is stereo (`channels: 2`, left = mic, right = system audio) when its first take used a mic, else mono (`channels: 1`, also every meeting recorded before stereo); the layout is kept in `rec.json` and later takes follow it (a stereo meeting recorded without a mic gets a silent left channel). `stop` writes `audio.wav` (mono mix of both channels) and, for stereo, `audio.mic.wav` and `audio.system.wav` (mono 16 kHz each), and deletes the macOS take file once folded in. Devices come from `.fused/data/settings.json` (default output monitor and default input unless set; on macOS the mic is an AVFoundation device name and system audio is always everything the Mac plays). Starting a recording captures everything the machine plays. ffmpeg is the one on PATH, else the bundled imageio-ffmpeg (macOS).
- Args: `action` (str, default "status": one of capabilities | settings | meter | status | prepare | start | pause | resume | stop | slice), `meeting_id` (str, required for status/prepare/start/pause/resume/stop/slice), `mic` (bool, default true, start only; false records without the mic), `system_file` (str, macOS start only: the take path from `prepare`, already being recorded), `system_capture` (str, macOS start only: the `fused.capture` id, stored so the page can re-attach), `started_at` (float epoch seconds, macOS start only: when that capture started; the mic is padded to it), `frm` / `to` (float seconds, slice only), `channel` (str, default "mix": mix | mic | system, slice only; mic/system on a mono meeting return the mono audio), `snap` (float seconds, default 0, slice only: move `to` back to the quietest 50 ms of the mix within `[to - snap, to]`, keeping the slice at least 0.5 s), `system` (str, settings only: source name of the output monitor, "" = default), `mic_device` (str, settings only: source name, "" = default, "off" = no mic), `secs` (float, default 0.5, meter only; macOS meters the mic only)
- Returns: status/start/stop → `{meeting_id, running, channels, levels, seconds, bytes, mic, monitor, mic_device, started_at, wav, wav_mic, wav_system, error, native, system_capture}` (`native` = a macOS take; start adds `mic_error` when the mic could not be opened and the take records system audio only; pause/resume freeze or continue a macOS take's ffmpeg while its capture is paused) plus `levels_mic`, `levels_system` when stereo (`levels` = dBFS per 50 ms over the last second while running, the louder of the two channels when stereo; `wav_mic`/`wav_system` = paths or null); capabilities/settings → `{available, reason, install, native, sink, monitor, monitor_label, mic, mic_label, default_monitor, default_mic, settings, devices:[{name,label,monitor}], current}` (`install` = a shell command that installs the missing tools, or null; `native` = macOS); prepare → `{system_file}` (absolute path in the meeting folder); meter → `{system:{device, levels, error}, mic:{device, levels, error}}`; slice → `{path, from, to, seconds, channel, peak_db, quiet_db}` (a mono 16 kHz WAV in `.fused/cache/slices/`; `to` is the snapped end; `channel` is the one actually used; `peak_db` = loudest 50 ms of the slice in dBFS; `quiet_db` = level of the window it cut at, null when not snapped)
- Example: `{"action":"py","app":"meeting-notes","file":"recorder.py","args":{"action":"meter","secs":"0.5"}}`

## gcal.py
Lists calendar events around now from the Google Calendar secret iCal address saved in `.fused/data/calendar.json`. Fetches the feed over the network at most every 5 min; writes only its cache in `.fused/cache/calendar/`.
- Args: `action` (str, default "upcoming": one of upcoming | status), `hours_back` (float, default 3), `hours_ahead` (float, default 24), `refresh` (bool, default false: fetch now instead of using a cache under 5 min old)
- Returns: upcoming → `{configured, events: [{uid, start, end, title, location, link, attendees: [{name, email, status}], people, invited}], fetched_at, error, now}` (`people` = accepted attendees, or everyone not declined when fewer than two accepted; `invited` = everyone not declined; times are epoch seconds); status → `{configured}`
- Example: `{"action":"py","app":"meeting-notes","file":"gcal.py","args":{"action":"upcoming","hours_ahead":"8"}}`
